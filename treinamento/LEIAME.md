# Página de treinamento

Simulador do RondaLuz (celular do motoqueiro + computador do líder) com dados de exemplo,
mapa ilustrativo e GPS simulado. Usa o código real de `js/` com um Supabase de mentira em memória.

Gerar a página: `python3 treinamento/build.py` → cria `treinamento/rondaluz-treinamento.html`
(um arquivo só, publicado como artefato no Claude). O arquivo gerado não vai para o Git.
